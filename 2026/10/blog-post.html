Η κριτική δεν κατοικεί στο παρόν

3 Οκτωβρίου 2026

Πώς θα διαβάζει η τεχνητή νοημοσύνη τις κριτικές ενός κόσμου που αλλάζει;

Μια κριτική γράφεται συνήθως λίγο μετά από ένα γεγονός. Κάποιος έμεινε σε ένα σπίτι, έφαγε σε ένα εστιατόριο, ταξίδεψε με ένα μέσο μεταφοράς. Επιστρέφει και γράφει τι συνάντησε. Το γεγονός έχει τελειώσει, αλλά η πρότασή του μένει διαθέσιμη σε ανθρώπους που δεν ήταν εκεί.

Αυτό φαίνεται απλό ώσπου να ρωτήσουμε πότε ακριβώς ισχύει εκείνο που διαβάζουν. «Η πόρτα δεν έκλεινε καλά» μπορεί να είναι απολύτως αληθές για μια νύχτα. Έπειτα η πόρτα επισκευάζεται. Η πρόταση δεν έγινε ψεύτικη· έγινε παλιά. Όποιος την έγραψε δεν έχει λόγο να την πάρει πίσω, αφού πράγματι έτσι βρήκε την πόρτα. Όποιος τη διαβάζει σήμερα, όμως, μπορεί να πάρει μια λανθασμένη απόφαση αν ακούσει τον παρελθοντικό χρόνο της σαν περιγραφή του παρόντος.

Ο κόσμος αλλάζει, ενώ οι κριτικές διατηρούνται. Η συνύπαρξη αυτή είναι χρήσιμη και δύσκολη μαζί. Χάρη στις κριτικές μαθαίνουμε πράγματα που μια φωτογραφία καταχώρισης δεν θα μας έλεγε. Χάρη στη διάρκειά τους, όμως, κάτι που διορθώθηκε μπορεί να συνεχίζει να εμφανίζεται σαν ενεργό πρόβλημα. Το αντίστροφο ισχύει εξίσου: μια παλιά εξαιρετική κριτική δεν εγγυάται ότι η σημερινή κατάσταση παραμένει εξαιρετική.

Δεν αρκεί, επομένως, να χωρίζουμε τις κριτικές σε θετικές και αρνητικές. Χρειάζεται να θυμόμαστε ότι καθεμία απαντά σε μια ερώτηση που σπάνια γράφεται: Πώς ήταν για αυτόν τον άνθρωπο, υπό αυτές τις συνθήκες, εκείνη τη στιγμή; Ο αναγνώστης έχει άλλη ερώτηση: Πώς θα είναι για μένα, υπό τις δικές μου συνθήκες, όταν θα πάω; Η απόσταση ανάμεσα στις δύο ερωτήσεις είναι το πραγματικό αντικείμενο της ανάγνωσης.

Πέντε αστέρια δεν περιέχουν τον λόγο του ταξιδιού. Μια καθυστερημένη άφιξη μπορεί να κάνει τις οδηγίες εισόδου καθοριστικές, ενώ για κάποιον που φτάνει μεσημέρι το ίδιο σημείο θα περάσει απαρατήρητο. Η εγγύτητα σε μια συγκεκριμένη διεύθυνση μπορεί να αξίζει περισσότερο από μια παροχή που συγκεντρώνει επαίνους. Άλλος χρειάζεται ησυχία για ύπνο, άλλος προσβασιμότητα, άλλος δυνατότητα να αλλάξει το πρόγραμμά του χωρίς μεγάλη απώλεια. Η ίδια διαμονή δεν απαντά με τον ίδιο τρόπο σε όλες αυτές τις ανάγκες.

Σήμερα η πλατφόρμα ζητά από τον επισκέπτη να μετατρέψει την εμπειρία του σε βαθμολογία. Αύριο ένα γλωσσικό σύστημα μπορεί να αναλάβει να διαβάσει εκατοντάδες βαθμολογίες και κείμενα αντί για τον επόμενο επισκέπτη. Θα ήταν δελεαστικό να του ζητήσουμε μια καθαρή απάντηση: «Αξίζει να κλείσω αυτό το σπίτι;» Εκεί αρχίζει ο κίνδυνος. Μια απάντηση μπορεί να είναι εύχρηστη ακριβώς επειδή έχει εξαφανίσει τις διαφορές που χρειαζόμασταν για να αποφασίσουμε.

Αν ένα σύστημα διαβάσει δέκα παλιές αναφορές για έναν θόρυβο και πει «το σπίτι έχει θόρυβο», μπορεί να μεταφέρει στο παρόν κάτι που δεν γνωρίζει. Αν διαβάσει δέκα πρόσφατες κριτικές που δεν αναφέρουν θόρυβο και πει «το πρόβλημα λύθηκε», πάλι μπορεί να ισχυριστεί περισσότερα απ’ όσα γνωρίζει. Η σιωπή των νεότερων επισκεπτών δεν είναι απόδειξη επισκευής. Μπορεί να μην άκουσαν τίποτε· μπορεί να το άκουσαν και να μη θεώρησαν ότι αξίζει να το γράψουν· μπορεί πράγματι να διορθώθηκε. Το σύστημα οφείλει να κρατήσει ανοιχτές αυτές τις δυνατότητες.

Το ίδιο ισχύει για την απόδοση ευθύνης. «Ένα αντικείμενο βρέθηκε σπασμένο» είναι παρατήρηση. «Δεν ενδιαφέρθηκε κανείς να το φτιάξει» είναι συμπέρασμα για μια αλυσίδα ανθρώπων που ο επισκέπτης συνήθως δεν βλέπει: εκείνον που καθαρίζει, εκείνον που παραλαμβάνει μια αναφορά, εκείνον που αποφασίζει, εκείνον που επισκευάζει. Μια κριτική μπορεί να δώσει πολύτιμη πληροφορία χωρίς να γνωρίζει πού ακριβώς διακόπηκε αυτή η αλυσίδα. Αν η τεχνητή νοημοσύνη μετατρέψει την παρατήρηση σε βέβαιη εξήγηση, δεν θα έχει διαβάσει καλύτερα από τον άνθρωπο. Θα έχει απλώς μιλήσει με περισσότερη αυτοπεποίθηση.

Θα ήθελα, λοιπόν, ένα γλωσσικό σύστημα που δεν κατασκευάζει αμέσως ετυμηγορία. Να μπορεί να πει: «Τον συγκεκριμένο μήνα αναφέρθηκε αυτό το ζήτημα. Σε μεταγενέστερες κριτικές εμφανίζεται ξανά» — ή «δεν εμφανίζεται ξανά, αλλά δεν υπάρχουν αρκετά στοιχεία για να ξέρουμε γιατί». Να ξεχωρίζει αυτό που έζησε ο συντάκτης από την ερμηνεία του, και την απάντηση του διαχειριστή από ανεξάρτητη επιβεβαίωση ότι έγινε κάποια αλλαγή. Να δίνει στον αναγνώστη τη δυνατότητα να επιστρέψει στις ίδιες τις μαρτυρίες, αντί να ζητά εμπιστοσύνη σε μια αόρατη σύνθεση.

Ένα τέτοιο σύστημα δεν θα χρειαζόταν να προσποιείται ότι είναι ουδέτερο. Θα έπρεπε να γνωρίζει για ποιον διαβάζει. Αν του πω ότι θα φτάσω αργά και χρειάζομαι σαφή τρόπο εισόδου, μια πρόσφατη αναφορά για δυσκολία στην άφιξη αποκτά ιδιαίτερη σημασία. Αν φτάσω μέρα και με περιμένει γνωστός μου στην περιοχή, ίσως όχι. Το σύστημα δεν αλλάζει το γεγονός της κριτικής. Αλλάζει την ερώτηση στην οποία το γεγονός μπορεί να βοηθήσει να απαντήσουμε.

Αυτό είναι κάτι περισσότερο από τεχνική βελτίωση των προτάσεων αγοράς. Είναι ένας τρόπος να μη φορτώνουμε σε μια μαρτυρία βάρος που δεν μπορεί να σηκώσει. Ο άνθρωπος που γράφει γνωρίζει τη δική του εμπειρία. Ο άνθρωπος που διαβάζει γνωρίζει τη δική του ανάγκη. Εκείνος που διαχειρίζεται έναν χώρο γνωρίζει, ή μπορεί να ελέγξει, τι άλλαξε στο μεταξύ. Καμία από αυτές τις θέσεις δεν περιέχει μόνη της ολόκληρη την εικόνα.

Ίσως αυτό να είναι το πιο χρήσιμο έργο της τεχνητής νοημοσύνης μπροστά στις κριτικές: όχι να αποφασίζει γρηγορότερα ποιος είχε δίκιο, αλλά να εμποδίζει τον χρόνο, την περίσταση και την αβεβαιότητα να χαθούν μέσα στην ταχύτητα της απόφασης. Να κρατά αληθινό το «έτσι ήταν τότε», χωρίς να το μεταφράζει αυθαίρετα σε «έτσι είναι πάντα».
