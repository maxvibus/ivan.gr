Η κριτική δεν κατοικεί στο παρόν

Δημοσιεύτηκε στις 3 Οκτωβρίου 2026 · 4 λεπτά ανάγνωσης

Πώς θα διαβάζει η τεχνητή νοημοσύνη τις κριτικές ενός κόσμου που αλλάζει;

Μια κριτική γράφε­ται συνήθως λίγο μετά από ένα γεγονός. Κάποιος έμεινε σε ένα σπίτι, έφαγε σε ένα εστια­τόριο, τα­ξί­δε­ψε με ένα μέσο με­τα­φο­ράς. Επι­στρέφει και γράφει τι συ­νάντη­σε. Το γεγονός έχει τε­λειώσει, αλλά η πρότασή του μένει δια­θέσι­μη σε αν­θρώπους που δεν ήταν εκεί.

Αυτό φαί­νε­ται απλό ώσπου να ρω­τή­σου­με πότε ακριβώς ισχύει εκείνο που δια­βάζουν. «Η πόρτα δεν έκλεινε καλά» μπορεί να είναι απο­λύ­τως αληθές για μια νύχτα. Έπειτα η πόρτα επι­σκευάζε­ται. Η πρόταση δεν έγινε ψεύτικη· έγινε παλιά. Όποιος την έγραψε δεν έχει λόγο να την πάρει πίσω, αφού πράγ­μα­τι έτσι βρήκε την πόρτα. Όποιος τη δια­βάζει σήμερα, όμως, μπορεί να πάρει μια λαν­θα­σμένη απόφαση αν ακούσει τον πα­ρελ­θο­ντι­κό χρόνο της σαν πε­ρι­γρα­φή του πα­ρόντος.

Ο κόσμος αλλάζει, ενώ οι κρι­τι­κές δια­τη­ρού­νται. Η συ­νύ­παρ­ξη αυτή είναι χρήσιμη και δύσκολη μαζί. Χάρη στις κρι­τι­κές μα­θαί­νου­με πράγ­μα­τα που μια φω­το­γρα­φία κα­τα­χώρι­σης δεν θα μας έλεγε. Χάρη στη διάρ­κειά τους, όμως, κάτι που διορ­θώθη­κε μπορεί να συ­νε­χί­ζει να εμ­φα­νί­ζε­ται σαν ενεργό πρόβλη­μα. Το αντί­στρο­φο ισχύει εξίσου: μια παλιά εξαι­ρε­τι­κή κριτική δεν εγ­γυάται ότι η ση­με­ρι­νή κα­τάστα­ση πα­ρα­μένει εξαι­ρε­τι­κή.

Δεν αρκεί, επο­μένως, να χω­ρί­ζου­με τις κρι­τι­κές σε θετικές και αρ­νη­τι­κές. Χρειάζε­ται να θυ­μόμα­στε ότι καθεμία απαντά σε μια ερώτηση που σπάνια γράφε­ται: Πώς ήταν για αυτόν τον άνθρωπο, υπό αυτές τις συν­θή­κες, εκείνη τη στιγμή; Ο ανα­γνώστης έχει άλλη ερώτηση: Πώς θα είναι για μένα, υπό τις δικές μου συν­θή­κες, όταν θα πάω; Η απόστα­ση ανάμεσα στις δύο ερω­τή­σεις είναι το πραγ­μα­τι­κό αντι­κεί­με­νο της ανάγνω­σης.

Πέντε αστέρια δεν πε­ριέχουν τον λόγο του τα­ξι­διού. Μια κα­θυ­στε­ρη­μένη άφιξη μπορεί να κάνει τις οδηγίες εισόδου κα­θο­ρι­στι­κές, ενώ για κάποιον που φτάνει με­ση­μέρι το ίδιο σημείο θα περάσει απα­ρα­τή­ρη­το. Η εγ­γύ­τη­τα σε μια συ­γκε­κρι­μένη διεύ­θυν­ση μπορεί να αξίζει πε­ρισ­σότε­ρο από μια παροχή που συ­γκε­ντρώνει επαί­νους. Άλλος χρειάζε­ται ησυχία για ύπνο, άλλος προ­σβα­σι­μότη­τα, άλλος δυ­να­τότη­τα να αλλάξει το πρόγραμ­μά του χωρίς μεγάλη απώλεια. Η ίδια διαμονή δεν απαντά με τον ίδιο τρόπο σε όλες αυτές τις ανάγκες.

Σήμερα η πλατ­φόρ­μα ζητά από τον επι­σκέπτη να με­τα­τρέψει την εμπει­ρία του σε βαθ­μο­λο­γία. Αύριο ένα γλωσ­σι­κό σύστημα μπορεί να ανα­λάβει να δια­βάσει εκα­το­ντάδες βαθ­μο­λο­γί­ες και κείμενα αντί για τον επόμενο επι­σκέπτη. Θα ήταν δε­λε­α­στι­κό να του ζη­τή­σου­με μια καθαρή απάντη­ση: «Αξίζει να κλείσω αυτό το σπίτι;» Εκεί αρχίζει ο κίν­δυ­νος. Μια απάντη­ση μπορεί να είναι εύ­χρη­στη ακριβώς επειδή έχει εξα­φα­νί­σει τις δια­φο­ρές που χρεια­ζόμα­σταν για να απο­φα­σί­σου­με.

Αν ένα σύστημα δια­βάσει δέκα παλιές ανα­φο­ρές για έναν θόρυβο και πει «το σπίτι έχει θόρυβο», μπορεί να με­τα­φέρει στο παρόν κάτι που δεν γνω­ρί­ζει. Αν δια­βάσει δέκα πρόσφα­τες κρι­τι­κές που δεν ανα­φέρουν θόρυβο και πει «το πρόβλη­μα λύθηκε», πάλι μπορεί να ισχυ­ρι­στεί πε­ρισ­σότε­ρα απ’ όσα γνω­ρί­ζει. Η σιωπή των νε­ότε­ρων επι­σκε­πτών δεν είναι απόδει­ξη επι­σκευ­ής. Μπορεί να μην άκουσαν τίποτε· μπορεί να το άκουσαν και να μη θε­ώρη­σαν ότι αξίζει να το γράψουν· μπορεί πράγ­μα­τι να διορ­θώθη­κε. Το σύστημα οφείλει να κρα­τή­σει ανοι­χτές αυτές τις δυ­να­τότη­τες.

Το ίδιο ισχύει για την απόδοση ευθύνης. «Ένα αντι­κεί­με­νο βρέθηκε σπα­σμένο» είναι πα­ρα­τή­ρη­ση. «Δεν εν­δια­φέρ­θη­κε κανείς να το φτιάξει» είναι συ­μπέρα­σμα για μια αλυσίδα αν­θρώπων που ο επι­σκέπτης συνήθως δεν βλέπει: εκείνον που κα­θα­ρί­ζει, εκείνον που πα­ρα­λαμ­βάνει μια αναφορά, εκείνον που απο­φα­σί­ζει, εκείνον που επι­σκευάζει. Μια κριτική μπορεί να δώσει πο­λύ­τι­μη πλη­ρο­φο­ρία χωρίς να γνω­ρί­ζει πού ακριβώς δια­κόπη­κε αυτή η αλυσίδα. Αν η τεχνητή νοη­μο­σύ­νη με­τα­τρέψει την πα­ρα­τή­ρη­ση σε βέβαιη εξήγηση, δεν θα έχει δια­βάσει κα­λύ­τε­ρα από τον άνθρωπο. Θα έχει απλώς μιλήσει με πε­ρισ­σότε­ρη αυ­το­πε­ποί­θη­ση.

Θα ήθελα, λοιπόν, ένα γλωσ­σι­κό σύστημα που δεν κα­τα­σκευάζει αμέσως ετυ­μη­γο­ρία. Να μπορεί να πει: «Τον συ­γκε­κρι­μένο μήνα ανα­φέρ­θη­κε αυτό το ζήτημα. Σε με­τα­γε­νέστε­ρες κρι­τι­κές εμ­φα­νί­ζε­ται ξανά» — ή «δεν εμ­φα­νί­ζε­ται ξανά, αλλά δεν υπάρ­χουν αρκετά στοι­χεία για να ξέρουμε γιατί». Να ξε­χω­ρί­ζει αυτό που έζησε ο συ­ντάκτης από την ερ­μη­νεία του, και την απάντη­ση του δια­χει­ρι­στή από ανε­ξάρ­τη­τη επι­βε­βαί­ω­ση ότι έγινε κάποια αλλαγή. Να δίνει στον ανα­γνώστη τη δυ­να­τότη­τα να επι­στρέψει στις ίδιες τις μαρ­τυ­ρί­ες, αντί να ζητά εμπι­στο­σύ­νη σε μια αόρατη σύνθεση.

Ένα τέτοιο σύστημα δεν θα χρεια­ζόταν να προ­σποιεί­ται ότι είναι ου­δέτε­ρο. Θα έπρεπε να γνω­ρί­ζει για ποιον δια­βάζει. Αν του πω ότι θα φτάσω αργά και χρειάζο­μαι σαφή τρόπο εισόδου, μια πρόσφα­τη αναφορά για δυ­σκο­λία στην άφιξη αποκτά ιδιαί­τε­ρη σημασία. Αν φτάσω μέρα και με πε­ρι­μένει γνωστός μου στην περιοχή, ίσως όχι. Το σύστημα δεν αλλάζει το γεγονός της κρι­τι­κής. Αλλάζει την ερώτηση στην οποία το γεγονός μπορεί να βοη­θή­σει να απα­ντή­σου­με.

Αυτό είναι κάτι πε­ρισ­σότε­ρο από τεχνική βελ­τί­ω­ση των προ­τάσε­ων αγοράς. Είναι ένας τρόπος να μη φορ­τώνου­με σε μια μαρ­τυ­ρία βάρος που δεν μπορεί να σηκώσει. Ο άν­θρω­πος που γράφει γνω­ρί­ζει τη δική του εμπει­ρία. Ο άν­θρω­πος που δια­βάζει γνω­ρί­ζει τη δική του ανάγκη. Εκείνος που δια­χει­ρί­ζε­ται έναν χώρο γνω­ρί­ζει, ή μπορεί να ελέγξει, τι άλλαξε στο μεταξύ. Καμία από αυτές τις θέσεις δεν πε­ριέχει μόνη της ολόκλη­ρη την εικόνα.

Ίσως αυτό να είναι το πιο χρήσιμο έργο της τε­χνη­τής νοη­μο­σύ­νης μπροστά στις κρι­τι­κές: όχι να απο­φα­σί­ζει γρη­γο­ρότε­ρα ποιος είχε δίκιο, αλλά να εμπο­δί­ζει τον χρόνο, την πε­ρί­στα­ση και την αβε­βαιότη­τα να χαθούν μέσα στην τα­χύ­τη­τα της απόφα­σης. Να κρατά αληθινό το «έτσι ήταν τότε», χωρίς να το με­τα­φράζει αυ­θαί­ρε­τα σε «έτσι είναι πάντα».
